Speak to your robot. This capstone module combines Whisper speech-to-text, LLM-based cognitive planning, and motor control into a voice-driven action pipeline — the full stack from Modules 1–3 assembled into one autonomous humanoid.

Starts with *Voice-to-Action with Whisper*.

<InfoBox type="info" title="Prerequisites">
  Requires Modules 1–3: ROS 2 (Module 1), simulation (Module 2), and the Isaac perception stack (Module 3). The capstone project builds on all three.
</InfoBox>
